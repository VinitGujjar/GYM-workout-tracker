# Privacy Policy — GYM Workout Tracker

**Last updated:** August 2026

**Created by:** its_vinitgujjar

GYM Workout Tracker is a personal workout-tracking application.

## Information You Enter

Depending on enabled features, the application may store:

- Workout plans
- Exercise names
- Sets, reps, weight and RIR
- Workout dates and duration
- Workout notes
- Bodyweight and measurements
- Progress information
- Authentication-related account information

## Local Storage

The application may store workout information locally in your browser/device for fast use and offline-friendly operation.

## Firebase

When cloud synchronization is enabled, application data may be stored using Firebase services associated with the GYM Workout Tracker project. Authentication may use Google Sign-In.

Cloud data should be protected using authenticated user access rules.

## Progress Photos

If progress-photo functionality is enabled, photos should be treated as private personal data and stored using authenticated/private storage. Private photos should never be committed to a public GitHub repository.

## Data Sharing

GYM Workout Tracker is not intended to sell personal workout data. Third-party services may process information as necessary to provide enabled authentication, hosting, database, advertising or other services.

## Your Responsibility

Do not enter highly sensitive information into workout notes or fields that are not designed for sensitive data.

## Changes

This policy may be updated when application functionality changes.
