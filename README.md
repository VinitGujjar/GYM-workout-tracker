# GYM Workout Tracker

A mobile-first personal gym workout tracker for planning workouts, logging exercises, tracking progress, and keeping workout history.

**Created by:** its_vinitgujjar

## Features

- Weekly workout plan
- Daily workout logging
- Sets, reps, weight and RIR
- Workout history
- Exercise progress tracking
- Personal records
- Workout duration and rest timer
- Bodyweight and measurements
- CSV workout-history export
- Firebase cloud sync
- Google Sign-In
- Offline-friendly local saving
- Mobile-first interface
